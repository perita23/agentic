# Contribuir

**Por ahora Agentic no acepta contribuciones.** No se revisarán ni se fusionarán pull requests, parches ni código de terceros, y no hace falta que prepares ninguno: el proyecto lo mantiene su autor.

## Lo que sí puedes hacer

- **Descargar y usar la aplicación gratis** para fines no comerciales, según la [licencia](LICENSE) (PolyForm Noncommercial 1.0.0).
- **Avisar de un fallo o proponer una idea** abriendo un *issue*. Se leen, pero no se garantiza respuesta ni plazo.
- **Informar de un problema de seguridad** contactando con el autor de forma privada, sin publicar los detalles en un issue abierto.

## Por qué

Aceptar contribuciones exige decidir antes cómo se licencian y quién conserva los derechos de ese código, y por ahora el autor prefiere mantener el proyecto bajo su propia autoría. Si esto cambia, se anunciará en el README y se publicará una guía de contribución.
